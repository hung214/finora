# 驗收規格：F08 — App 鎖與資料安全

| 項目 | 內容 |
|---|---|
| 對應 BDD | `BDD.md` Feature 8（6 個 Scenario） |
| 對應需求 | SPEC FR-X1、FR-X3、FR-X5（§5.9） |
| 對應驗收場景 | AC-09 |
| 里程碑 / 優先級 | M7 / P0（S8.6 為 P1） |
| 所需環境 | 具生物辨識裝置（iPhone Face ID / Android 指紋 / Windows Hello / macOS Touch ID）；已連結雲端帳號（S8.4）；未連結雲端的乾淨環境（S8.5） |

## 前置條件（每情境開始前重置）

| 資料 | 內容 |
|---|---|
| 鎖定設定 | PIN = 1234、生物辨識已註冊、背景鎖定門檻 30 秒 |
| 雲端 | S8.1~S8.4 已連結；S8.5 未連結 |
| 資料 | 帳本含 20 筆交易（用於驗證「資料保留」） |

## S8.1 背景逾時鎖定（@FR-X1 @AC-09 @P0 @M7）

| # | 操作 | 預期結果 |
|---|---|---|
| 1 | App 切至背景，等待 **31 秒**後返回 | 顯示鎖定畫面（遮蔽內容，不可下滑偷看） |
| 2 | 使用 Face ID 成功解鎖 | 進入 App，資料完整可見，停留於離開前的畫面 |
| 3 | 重複但等待 29 秒返回 | **不**鎖定（對照組） |

**通過標準**：門檻判定精準（30s 邊界）；鎖定畫面不可透視底下內容。
**失敗判定**：鎖定畫面能看到餘額/交易 ＝ **Critical**（隱私破口）。
**實例走查**：小明在捷運上把 App 切去回訊息，30 秒後回來——畫面已上鎖，Face ID 一掃即解，旁人完全看不到他的帳目。

## S8.2 門檻內返回不鎖定（@FR-X1 @P0 @M7）

| # | 操作 | 預期結果 |
|---|---|---|
| 1 | App 切背景 **10 秒**內返回 | 不出現鎖定畫面 |
| 2 | 反覆切換 5 次 | 皆不鎖定；無累積誤判 |

**通過標準**：短暫切換（截圖比對、回訊息）不被打擾。
**邊界與例外**：使用者可於設定調整門檻（如 5 秒/30 秒/立即）；設「立即」時任何切背景都鎖。

## S8.3 生物辨識連續失敗退回 PIN（@FR-X1 @P0 @M7）

| # | 操作 | 預期結果 |
|---|---|---|
| 1 | Face ID 連續失敗 3 次（他人嘗試解鎖） | 第 3 次後改為要求輸入 PIN |
| 2 | 輸入錯誤 PIN 5 次 | 進入冷卻（如 30 秒倒數），防止暴力嘗試 |
| 3 | 冷卻後輸入正確 PIN 1234 | 解鎖成功 |

**通過標準**：生物辨識退場機制 + PIN 節流皆生效；冷卻期間不洩漏「PIN 是否正確」資訊。

## S8.4 PIN 遺忘_已連結雲端_重新登入帳號後重設（@FR-X5 @P0 @M7）

| # | 操作 | 預期結果 |
|---|---|---|
| 1 | 鎖定畫面點「忘記 PIN」 | 顯示「透過雲端帳號驗證身分以重設」 |
| 2 | 重新登入**同一**雲端帳號（OAuth） | 驗證通過 |
| 3 | 設定新 PIN（如 5678）+ 重新註冊生物辨識 | 完成 |
| 4 | 檢查本地資料 | 20 筆交易**完整保留** |
| 5 | 之後解鎖 | 新 PIN/生物辨識生效 |

**通過標準**：身分驗證 = 雲端帳號重新登入（非 Email/安全問題等弱機制）；資料零損失。
**失敗判定**：重設過程清空本地資料 ＝ **Critical**。
**實例走查**：阿花忘了 PIN——她按「忘記 PIN」，重新登入 Google 帳號，設好新 PIN，帳本原封不動。

## S8.5 PIN 遺忘_未連結雲端_僅能重置 App（@FR-X5 @P0 @M7）

| # | 操作 | 預期結果 |
|---|---|---|
| 1 | 未連結雲端的環境，鎖定畫面點「忘記 PIN」 | **僅**提供「重置 App」選項（無帳號驗證路徑） |
| 2 | 點重置 | 要求輸入確認文字（如「我要清除所有資料」） |
| 3 | 完成確認 | 本地資料清空，回到首次啟動引導 |
| 4 | 檢查安全日誌 | 重置事件已記錄 |

**通過標準**：無雲端時不存在任何繞過 PIN 而保留資料的路徑（設計取捨，文案需清楚警告）。
**失敗判定**：有隱藏後門可免清除解鎖 ＝ **Blocker**（安全漏洞）。

## S8.6 隱私遮蔽模式（@FR-X3 @P1 @M7）

| # | 操作 | 預期結果 |
|---|---|---|
| 1 | 總覽頁開啟金額遮蔽 | 所有金額變 ●●●●（圖表同步遮蔽） |
| 2 | 切換開關 | 即時生效（<100ms） |
| 3 | iOS：切至 App 切換器 | 預覽畫面模糊（防任務切換器偷看） |

**通過標準**：遮蔽覆蓋所有金額顯示點（卡片、清單、圖表、小工具）。
**邊界與例外**：遮蔽狀態截圖 → 圖中金額為遮蔽樣式；登出/重裝後遮蔽狀態回預設（關）。
